## 5. ERRORES ENCONTRADOS DURANTE LA FASE

1. `adb shell cmd power get-fixed-performance-mode-enabled` → `Unknown command` (limitación del build ZTE; solo documentada, no bloqueante).
2. Intento 1 de is_running edit: `run-as sh -c 'sed … > …new'` → "No such file or directory" (cwd de run-as no es el dir interno).
3. Intento 2: `cd /data/data/... && …` → "Read-only file system" (run-as restringe la escritura indirecta).
4. Solución (intento 3): pull del XML → edición local con sed → push de vuelta vía `run-as sh -c 'cat > shared_prefs/gameboost_prefs.xml'` con stdin redirigido — exitoso, verificado.
