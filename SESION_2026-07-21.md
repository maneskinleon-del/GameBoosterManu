## Comandos verificados en el dispositivo

### ✅ Funcionan desde shell UID 2000 (Shizuku)

```
settings put global <key> <value>    → Todo lo que sea settings put global ✅
cmd power set-fixed-performance-mode-enabled true/false
cmd power set-adaptive-power-saver-enabled true/false
settings put system peak_refresh_rate / min_refresh_rate
settings put system pointer_speed
settings put secure long_press_timeout
settings put system touch_sensitivity
am force-stop <package>
dumpsys deviceidle force-idle
cmd thermalservice reset
cmd package compile -f -m speed <pkg>
cmd package bg-dexopt-job
wm density <dpi>
wm size <wxh> / wm size reset
logcat -c
dmesg -c
pidof <process>
```

### ❌ NO funcionan desde shell (bloqueados por SELinux)

```
echo performance > .../scaling_governor          → Permission denied
renice -n -10 -p <PID>                           → Operation not permitted
taskset -p <PID>                                 → Operation not permitted
sysctl -w net.ipv4.tcp_congestion_control=bbr    → Permission denied
cmd activity idle-systems <pkg>                  → Unknown command (no existe en AOSP)
```

## Bugs conocidos / Temas abiertos

1. **`renice` y `taskset` no funcionan** — `GameSessionManager.kt` líneas 415-419 aún los ejecutan. Fallan silenciosamente con log. Pendiente: decidir si eliminar o dejar como intento.
2. **`sysctl -w` no funciona** — `NetworkOptimizer.kt` aún lo intenta. Fallan con log. Pendiente: lo mismo.
3. **MSAA 4x GPU-intensive** — En dispositivos mid-range puede bajar FPS. Está en `SystemTweaks` como comando fijo. Considerar hacerlo toggle opcional.
4. **scrcpy 4.1 flag** — `--lock-video-orientation` no existe en 4.1, se reemplazó por `--capture-orientation=@`. El script `nubia_zte.sh` ya está corregido.
