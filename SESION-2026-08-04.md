## 🔧 Bugs corregidos

### 1. Bug #23 — Governor bloqueado por kernel (fb02730)

**Problema:** El comando `echo performance > /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor` fallaba en kernels que bloquean escrituras (ZTE, Xiaomi), causando "Fallo permanente" y congelamiento del teclado.

**Solución:**
- Agregada función `isGovernorWritable()` que verifica si el kernel permite escritura
- Si el governor no es escribible, hace skip con mensaje claro en vez de fallar
- Sanitización de shell con `sanitizeForShell()` para evitar inyección

**Archivos modificados:**
- `GameSessionManager.kt` — `isGovernorWritable()` + skip en `executePrivilegedCommands()`
- `ProfileManager.kt` — `sanitizeForShell()` + governor sanitizado

### 2. DNS fix + Network on profile change (576caac)

**Problema:** 
- El comando `private_dns_spec` tenía bug de escaping en `RESTORE_COMMANDS`
- Las optimizaciones de red (DNS, WiFi, BT) solo se aplicaban al activar boost, no al cambiar de perfil

**Solución:**
- Corregido escaping en `NetworkOptimizer.kt` RESTORE_COMMANDS
- Agregado `networkOptimizer.apply()` en `GameSessionManager.setActiveProfile()`

**Archivos modificados:**
- `NetworkOptimizer.kt` — Fix escaping `private_dns_spec`
- `GameSessionManager.kt` — `networkOptimizer.apply()` en `setActiveProfile()`

### 3. UI — Indicador visual del perfil activo (c389949)

**Problema:** El indicador del perfil activo (círculo vacío pequeño) no era distintivo.

**Solución:**
- Badge **"ACTIVO"** con punto naranja (#FF9100)
- Borde de tarjeta grueso (2dp) en color naranja
- Fondo del ícono con brillo naranja estático
- Nombre del perfil en color naranja cuando activo
- Tags (governor, Hz) con fondo sutil naranja
- Constante `ActiveProfileOrange` para consistencia

**Archivos modificados:**
- `MainActivity.kt` — `ProfileCardCompact` + `ProfileTag` + `ActiveProfileOrange`

### 4. Remover animación de pulsado (a87a75e)

**Problema:** El fondo del perfil activo tenía animación de parpadeo/pulsado que el usuario no deseaba.

**Solución:**
- Removido `infiniteTransition` y `glowAlpha` del `ProfileCardCompact`
- Fondo del ícono activo ahora es estático (alpha 0.25)

**Archivos modificados:**
- `MainActivity.kt` — Eliminada animación `infiniteRepeatable`
